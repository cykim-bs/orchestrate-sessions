# 이 기기·프로젝트 규칙 (local-bindings)

> 이 파일은 **예시**다. `local-bindings.md`로 복사한 뒤 내 환경에 맞게 고친다.
> 없는 항목은 지워도 된다. 지운 항목은 SKILL.md의 기본값을 쓴다.
> 개인 정보·토큰·비밀번호는 적지 않는다.

## 진행 기록 위치

- 기본: `<프로젝트>/.orchestration/YYYYMMDD-<작업명>/` (git에 올리지 않으려면 `.gitignore`에 `.orchestration/` 추가)
- 바꾸려면: 예) `~/notes/<프로젝트>/YYYYMMDD-<작업명>/`

## 언어·말투

- 사용자에게 보이는 글: 예) 한국어 존댓말, 짧게

## git

- 커밋 메시지 형식: 예) `type: 요약` / `{영역} - {변경 내용}`
- push 기본값: 예) 사용자가 그 요청에서 말할 때만
- 병렬 작업 폴더: 예) git 워크트리 허용 / 워크트리 금지, 별도 클론 사용 / 같은 폴더에서 차례로만

## 공유 자원 잠금

여러 세션이 함께 쓰면 안 되는 것(에디터, DB, 기기, 빌드 서버)과 잡고 놓는 순서.

- 예) 게임 엔진 에디터: 한 번에 한 세션. 잠금 스크립트 `<경로> acquire` → 작업 → 커밋 → `release`
- 예) 로컬 DB 마이그레이션: 구현 세션만 실행

## 외부 보고

- 기본: 없음(사용자에게 대화로만 보고)
- 있으면: 예) 팀 채팅 채널 이름, 보내는 방법(스크립트·웹훅 환경변수 이름). 토큰 값은 적지 않는다.

## 프로젝트 금지 사항

- 예) `generated/` 폴더는 손으로 고치지 않는다
- 예) 새 패키지 설치는 사용자 허락 뒤에만

## 모델 표 덮어쓰기 (선택)

- 예) 계획 단계는 Opus high로 충분
