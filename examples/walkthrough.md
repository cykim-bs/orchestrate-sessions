# 따라가 보기: 「설정 화면에 다크 모드 추가」

가상의 웹 앱 프로젝트에서 이 스킬이 어떻게 흘러가는지 처음부터 끝까지 보여 주는 예시입니다.
실제 화면 문구는 앱 버전에 따라 조금 다를 수 있어요.

## 0. 내가 한 말

```text
설정 화면에 다크 모드를 추가해 줘. 서브세션으로 나눠서 진행해 줘.
```

지휘 세션은 앱에서 **Opus · high**로 골라 두었습니다.

## 1. 지휘 세션의 첫 응답

지휘 세션은 README와 `git log`를 잠깐 훑은 뒤 이렇게 답합니다.

> 다음 순서로 나눠서 진행할게요.
>
> | 단계 | 담당 모델 |
> |---|---|
> | ① 코드 조사: 지금 색상·테마 구조 | Sonnet · medium |
> | ② 자료 조사: 다크 모드 접근성 기준, 시스템 설정 따라가기 | Opus · medium |
> | ③ 계획 | Opus · high |
> | ④ 구현 | Opus · high |
> | ⑤ 테스트·스크린샷·push | Sonnet · medium |
>
> **코드 조사** — 테마 변수와 설정 화면 구조를 정리합니다.
> **자료 조사** — 대비 기준과 시스템 테마 감지 방법을 찾습니다.
>
> (두 세션 시작)
>
> 몇 가지만 한 번에 여쭐게요.
> - 마지막에 원격 저장소로 push까지 할까요?
> - 계획을 먼저 보고 구현할까요?

계획 단계는 원래 xhigh가 기본이지만, 지휘가 high로 시작했고 일이 크지 않아 high로 정했습니다.

## 2. 내 답

```text
push까지 해 줘. 계획은 안 보고 바로 진행해도 돼.
```

지휘는 이 말을 날짜와 함께 진행표에 적고, 나중에 ⑤ 세션 브리프에 **원문 그대로** 넣습니다.

## 3. 진행표 (중간)

`.orchestration/20261125-dark-mode/sessions.md`

| # | 단계 | 세션 이름 | 모델·추론 | 상태 | 산출물·커밋 | 지휘 확인 |
|---|---|---|---|---|---|---|
| 1 | 코드 조사 | dark-mode-code-survey | Sonnet medium | 끝 | research/code-survey.md | 120줄, 목차 확인 |
| 2 | 자료 조사 | dark-mode-research | Opus medium | 끝 | research/external.md | 추천안 절 확인 |
| 3 | 계획 | dark-mode-plan | Opus high | 진행 | | |

두 조사 세션이 끝나면 지휘가 깨어나 문서가 실제로 있는지, 필요한 절이 있는지 직접 확인한 뒤 계획 세션을 띄웁니다.

## 4. 구현 세션 브리프 (일부)

```text
plan.md의 「구현 단위」 1~3을 구현한다. 테스트 실행과 push는 하지 않는다(다음 세션 몫).

읽을 것(정본): .orchestration/20261125-dark-mode/plan.md
작업 장소: 이 프로젝트 폴더에서만 한다. main 브랜치.
허락(사용자 원문·날짜): 「push까지 해 줘. 계획은 안 보고 바로 진행해도 돼.」(2026-11-25). 이 세션 범위: 커밋까지. push 안 함.
커밋: 단위마다 하나씩.
결과 기록: result.md의 「구현」 절, 완료 기준 표.
마지막 답변: 커밋 해시, 완료 기준 통과 여부, 남은 문제.
```

## 5. 단계 사이 확인 (지휘가 직접)

구현 세션이 「끝났어요」라고 해도 지휘는 직접 봅니다.

```bash
git log --format='%h %ae %s' -5   # 커밋 3개, 메시지 형식
git status -sb                    # 남은 변경 없음
```

`result.md`의 완료 기준 표에 「통과 못 함」이 있으면 다음 단계로 넘기지 않고 구현 세션에 다시 보냅니다.

## 6. 마지막 보고

> 다크 모드를 추가했어요.
> - 바뀐 것: 테마 변수 2벌, 설정 화면 토글, 시스템 설정 따라가기
> - 검증: 테스트 48개 통과, 대비 4.5:1 이상(스크린샷 2장)
> - 커밋 3개, `origin/main`에 push 확인
> - 하지 않은 것: 차트 색상(별도 작업 권장)
>
> | 단계 | 모델 | 걸린 시간 |
> |---|---|---|
> | 조사 2개 | Sonnet medium / Opus medium | 6분 / 9분 |
> | 계획 | Opus high | 7분 |
> | 구현 | Opus high | 25분 |
> | 테스트·push | Sonnet medium | 5분 |
